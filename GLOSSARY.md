# Afterburner

Afterburner supplies application-specific guidance and capabilities to coding agents working on Laravel applications.

## Language

**Guideline**:
Instructions supplied as part of an agent's standing application context.

**Skill**:
A named set of instructions that an agent can load when a relevant task arises.

**Project rule**:
A durable convention, decision, or constraint specific to an application, with a scope identifying where it applies.

**Base preset**:
A named selection of guidelines and skills supplied by Afterburner, separate from the application's and its dependencies' own content.

**Core skill**:
An Afterburner-supplied skill that teaches an agent an operational workflow, such as recording project rules or finding relevant documentation.
